# Shikaku-Puzzle
Shikaku Puzzle Game

## Tech Stack
- Node.js
- Mongodb
- Socket.io
- Html css

## Installation

```bash
git clone https://github.com/MakrubiyaJatin/Shikaku-Puzzle.git

cd Shikaku-Puzzle

npm install

cp env.example .env
```
- Update env file as per your value of enviroment variable

## Run 
```bash
npm run start
```

## URL for play
```url
http://localhost:3000/play
```
